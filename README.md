# Tvorba-webove-mapove-aplikace-pro-vyhledavani-a-navigaci-mezi-geodetickymi-body-v-siti-bodu-FSv-CVUT
Webová mapová aplikace vytvořená jako součást bakalářské práce na Fakultě stavební ČVUT v Praze.

Aplikace slouží k:
- zobrazení geodetických bodů,
- vyhledávání bodů,
- navigaci pomocí přímé vzdálenosti,
- výpočtu nákladové vzdálenosti,
- zobrazení aktuální polohy uživatele.

## Online aplikace
https://bpvincenc.netlify.app/

## Použité technologie
### Frontend
- HTML
- CSS
- JavaScript
- Leaflet
- Turf.js

### Backend
- Python
- Flask
- Gunicorn

## Spuštění backendu
```bash
cd backend
pip install -r requirements.txt
python server.py
```
